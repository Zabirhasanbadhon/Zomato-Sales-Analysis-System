# 🍽️ Zomato Sales Analysis

A Python-based **Zomato Sales Analysis system** with a **Tkinter GUI** for analyzing restaurant and sales data from a CSV dataset.

## ✨ Features

- 🖥️ Tkinter GUI
- 📂 Load `Zomato Sales.csv`
- 🔎 Search and filter data
- 📊 Dashboard & KPIs
- 📈 Sales/cost visualization
- 🏆 Top restaurant analysis
- 🌆 City analysis
- ⭐ Rating analysis

## 🛠️ Technologies

- Python
- Tkinter
- Pandas
- NumPy
- Matplotlib
